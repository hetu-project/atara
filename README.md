# Atara Node Documentation

This documentation is for organisations considering running a node on the Atara network: compute providers, OTC desks, payment companies, and teams with custody or clearing capability.

It answers four questions:

1. What does a node do, at each of the three levels?
2. What does it take to enter a level, and to move up?
3. How is a node paid, and how fast?
4. What does a node post, and what does it lose when it errs?

It does not quote yields. Fee splits, thresholds and timing rules are design parameters; they are calibrated on live settlement data and listed in [Parameters](reference/parameters.md).

**How to read.** If you have five minutes, read [One payment, eight steps](getting-started/one-payment-eight-steps.md). If you are deciding whether to operate a node, read Roles, Progression and Earnings in order. Reference pages are for looking things up.
