# Five requirements

Promotion is not a new exam. It is the same exam with the pass mark raised. Every level is measured on the same five requirements; a higher level sets each bar higher.

## The five

| Requirement | What it measures | Can capital solve it? |
|---|---|---|
| Collateral | How much the node has posted | Yes, it can be bought |
| Reputation score | Quality of work done, accumulated over time | No, it can only be earned |
| Track record | How long the node has worked, and without error | No, it can only be waited out |
| Compute | Node specification and uptime | Yes, it can be built |
| Liability | How much the node pays when it errs | Taken on, not chosen |

What each level demands on each requirement is on the [role pages](../roles/overview.md) and summarised in [Parameters](../reference/parameters.md).

## Three rules

**The weakest requirement sets the level.** A node's level is the lowest of its five requirements. Capital can open ten thousand Light workers in a day. It cannot move a single one of them up, because reputation and track record are not for sale.

**Promotion and demotion are symmetric, and demotion is immediate.** A node is promoted when all five requirements cross the next line at the same time. It is demoted the moment any one falls below its current line. Reputation decays by about 2 percent per month if the node stops working, and track record is measured over a rolling window. A node that stops working watches its own bars slide.

**The higher the level, the less can be bought.** Entry to Light worker is mostly a matter of posting collateral and running a node. Entry to Adjudicator is mostly a matter of what the node has done.

## What this means for a new operator

Enter at the level your collateral and compute qualify you for today, which is almost always Light worker. Work. The other two requirements accumulate from the first settled transfer, and nothing else accumulates them.
